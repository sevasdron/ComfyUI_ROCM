# ADR-0003. Работаем в собственном контейнере, данные модпака — одна папка

Статус: **принято** · 14.09.2026

## Контекст

Рассматривались два способа: ComfyUI прямо в системе (venv через uv на каждую версию)
или в собственном контейнере. Скорость одинаковая: ядро и драйвер amdgpu общие,
ROCm в обоих случаях приезжает pip-колёсами.

Единственное, что не устраивало в контейнере, — непонятные точки монтирования:
в текущем toolbox рабочие папки разбросаны по домашней директории
(`~/comfy/custom_nodes`, `~/comfy/user`, `~/comfy/input`, `~/comfy-outputs`, `~/comfy-models`),
а в контейнер пробрасываются весь `/home`, весь `/mnt` и корень хоста.

## Решение

- Остаёмся в контейнере (слои по [ADR-0001](0001-layered-images.md)).
- Всё рабочее у модпака — одна папка `~/ComfyUI/<модпак>/` с подпапками
  `custom_nodes`, `user`, `input`, `output`, `temp`. Это стандартная раскладка
  `--base-directory`, поэтому она монтируется одним томом в `/data`.
- Модели — отдельное общее монтирование только для чтения
  (`/mnt/data/AI_Models/ComfyUI` → `/models`, `--models-directory`).
- Кэш HuggingFace — общее монтирование `/mnt/data/huggingface` → `/cache/hf`.
- Больше ничего с хоста в контейнер не пробрасывается.

## Почему не в системе

| | В системе | В контейнере |
|---|---|---|
| Обновление Fedora ломает сборку | может | нет |
| Системные пакеты для нод (ffmpeg, шрифты, Vulkan) | в хост | в образ |
| Доступ кода нод к файлам | весь `/home`, `/mnt` | только три монтирования |
| Откат | venv + git + dnf по отдельности | смена тега образа |
| Параллельные версии | отдельные venv и порты, вручную | stable/candidate из коробки |
| Правка ноды | сразу | тоже сразу: ноды смонтированы с хоста, нужен только рестарт |
| Место | меньше (жёсткие ссылки uv) | больше, ~25–35 ГБ рабочих |

## Последствия

- Переезд: `~/comfy/{custom_nodes,user,input}` и `~/comfy-outputs` переносятся в `~/ComfyUI/main/`.
  Текущий toolbox до завершения переезда работает на старых путях.
- Для монтирований из `/home` под SELinux нужна метка (`:z`) или `--security-opt label=disable`;
  выбрать при написании `tools/comfy run`.
- Хранилище образов остаётся на btrfs (`~/.local/share/containers`): на NTFS слои podman не хранятся.
