# Железо и системные настройки

Замеры сняты 14.09.2026 на самой машине.

## Платформа

| | |
|---|---|
| Машина | GMKtec EVO-X3 (BIOS `EVO-X3_V1.01`) |
| CPU | AMD Ryzen AI MAX+ 395, 16 ядер / 32 потока, AVX2 + AVX-512 |
| GPU | Radeon 8060S, архитектура **gfx1151** (Strix Halo, RDNA 3.5) |
| Память | 128 ГБ LPDDR5X, общая для CPU и GPU |
| ОС хоста | Fedora 44, ядро 7.2.4 |
| Диски | `nvme1n1p8` btrfs 129 ГБ (`/`, `/home`, свободно ~79 ГБ); `nvme0n1p5` NTFS 1.3 ТБ (`/mnt/data`, модели) |

## Как поделена память

| Что | Размер | Откуда |
|---|---|---|
| VRAM (выделено в BIOS) | 32 768 МиБ | `mem_info_vram_total` |
| Видит ОС | ~94 ГиБ | `MemTotal` |
| GTT — системная память, доступная GPU | 96 172 МиБ | `mem_info_gtt_total` |

Параметры ядра: `amdgpu.gttsize=126976 ttm.pages_limit=32505856 amd_iommu=off`.
`gttsize` просит ~124 ГиБ, но фактический GTT упирается в память, которую видит ОС.

**Что это значит для ComfyUI.** Одна модель может занять больше 32 ГБ: всё сверх
VRAM берётся из GTT, то есть из той же системной памяти, где живут Python, кэш
ComfyUI и страничный кэш. Реальный потолок одновременно загруженных весов — около
100 ГБ, и он общий для всех запущенных контейнеров.

## Практические выводы (проверено в работе)

- **`--disable-smart-memory` и `--cache-none` не нужны.** Рекомендация kyuz0 рассчитана на
  32 ГБ. Здесь тяжёлый видеопрогон MiniMax H3 держит ~50 ГБ (DiT 20 + энкодер 25 + VAE 5),
  запас двукратный. Без этих ключей ушли 12 перезагрузок модели за прогон.
- **`--gpu-only`** оставляет промежуточные тензоры на GPU. Ноды, которые зовут `.numpy()`
  без `.cpu()`, падают (см. GrowMask в [patches-registry.md](patches-registry.md)).
- **`--disable-mmap`** оставляем: модели лежат на NTFS через FUSE, mmap там медленный.
- **CUDA-only ядра не работают:** SageAttention, xformers, Nunchaku, NVENC.
  Для внимания есть `comfy_kitchen_attention` с бэкендом `hip`.
- **Параллельные контейнеры делят память.** Тяжёлые задачи — строго по очереди.

## Открытые вопросы

- 32 ГБ VRAM в BIOS против минимального выделения и большого GTT: что быстрее
  и стабильнее на ROCm 7.15 для наших моделей. Нужен замер, а не общая рекомендация.
- Vulkan-сборка llama.cpp внутри контейнера (нужен `mesa-vulkan-drivers`) против текущей CPU-сборки.
