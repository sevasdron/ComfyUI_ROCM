# TRELLIS.2 / Pixal3D image→model: параметры качества геометрии

Воркфлоу `3d_pixal3d_trellis2_image_to_model` (ComfyUI 0.35.1). Только то, что влияет на форму,
её разрешение и детализацию; текстуры и запекание не рассматриваются. Порядок — как выполняется.
«Сейчас» — значения в рабочем файле на 15.09.2026. Описания — по подсказкам самих нод.

## 1. Подготовка картинки

| Узел | Параметр | Сейчас | Диапазон | За что отвечает |
|---|---|---|---|---|
| `RemoveBackground#192` | модель `birefnet` | вкл (`Switch#248`) | — | Маска объекта. Ошибки маски (обрезанные тонкие части, захваченный фон) напрямую становятся ошибками формы |
| `ImageCropToMask#312` | `pad_factor` | 1.1 | 1.0–2.0 | Запас вокруг маски при кропе. Меньше — объект крупнее в кадре (DINO работает на 512/1024 px кропа), но края могут срезаться |
| | `grow_mask` | 0 | −32…32 px | Расширить (+) или сузить (−) маску перед кропом. + если срезаются тонкие края объекта |
| `MoGeInference#56` | `resolution_level` | 9 | 0–9 | Детализация оценки глубины (9 — максимум) |
| | `fov_x_degrees` | 0 (авто) | 0–170 | Горизонтальный угол камеры. Если объектив известен — задать вручную, точнее авто |
| | `apply_mask` | true | — | Вырезать фон из карты глубины |
| `Pixal3DConditioning#298` | `camera_angle_x` | из MoGe (`#242`) | 1–170° | Перспектива, с которой модель «смотрит» на фото. Режим Pixal3D (учитывает перспективу) выбран `Switch to Trellis2` = false — правильно для фотографий; Trellis2-режим — для ортографических рендеров |

## 2. Guidance (общие для стадий структуры и формы)

| Узел | Параметр | Сейчас | Диапазон | За что отвечает |
|---|---|---|---|---|
| `ModelSamplingSD3#108` (структура) | `shift` | 5.0 | 0–100 | Сдвиг расписания шума: больше — больше шагов уходит на крупную форму, меньше — на детали (умолчание ноды 3.0) |
| `RescaleCFG#125` (структура) / `#126` (форма) | `multiplier` | 0.7 / 0.5 | 0–1 | Гасит артефакты высокого CFG (пересушенность, «взрывы»). 0 — выкл |
| `CFGOverride#199` (структура) / `#279` (форма) | `cfg`, `start_percent` | 1.0 с 0.667 / 1.0 с 0.769 | 0–1 | На последней трети/четверти шагов guidance выключается. Раньше начало — мягче и «чище», позже — жёстче следует картинке, но больше артефактов |

## 3. Структура — разрежённые воксели (решает «что это за форма»)

| Узел | Параметр | Сейчас | Диапазон | За что отвечает |
|---|---|---|---|---|
| `KSampler#3` | `seed` | 56 | — | **Главный рычаг топологии.** Другой seed — другое расположение частей. «Нет тела / куски» лечится здесь перебором сидов, ниже по цепочке не чинится |
| | `steps` | 12 | 1–10000 | Шаги денойза структуры. Штатно 12; 15–25 — обычно чище, но результат меняется целиком (другая траектория) |
| | `cfg` | 7.5 | 0–100 | Сила следования картинке. Выше — точнее, но пересушивает; с `RescaleCFG`/`CFGOverride` 5–7.5 |
| | `sampler` / `scheduler` | euler / normal | — | Штатная пара; менять в последнюю очередь |
| `VaeDecodeStructureTrellis2#119` | `resolution` | 64 | 32 / 64 | Сетка структуры. 64 — тоньше детали и меньше «слипания» частей, ×4 времени `Pixal3DConditioning` (~11 мин). При 64 обязателен `RH Trellis2 Upsample Stage` вместо штатного |

## 4. Форма — поверхность на сетке структуры

| Узел | Параметр | Сейчас | Диапазон | За что отвечает |
|---|---|---|---|---|
| `KSampler#18` | `seed` / `steps` / `cfg` | 42 / 20 / 7.5 | — | Генерация поверхности на сетке 1024 при уже выбранной структуре. Отвечает за соответствие рельефа картинке |
| `RH Trellis2 Upsample Stage#94` | `target_resolution` | 1536 | 1024–2048, шаг 128 | **Разрешение финальной формы** (вокселей на сторону). Выше — детальнее и тяжелее по памяти. При структуре 64 проверено 1536; 2048 в одном прогоне дал разваленную форму — не считать безопасным |
| `KSampler#23` | `seed` / `steps` / `cfg` | 42 / 12 / 7.5, `simple` | — | Дорисовка на апсемпл-сетке — мелкий рельеф. Изменение шагов меняет и крупную форму |
| `VaeDecodeShapeTrellis#92` | — | — | — | Сырой меш формы (при 1536 ≈ 2 M вершин). Самый детальный, с «лесенкой» Dual Contouring |

## 5. Постобработка меша

| Узел | Параметр | Сейчас | Диапазон | За что отвечает |
|---|---|---|---|---|
| `RemeshMesh#241` | `resolution` | 768 | 32–2048 | Плотность перестроенной сетки (512 ≈ 1 M граней). Ниже разрешения формы — детали мельче ячейки теряются |
| | `band` | 1.0 | 0.5–4.0 | Ширина полосы вокруг поверхности **в вокселях remesh**. При подъёме `resolution` полоса в абсолюте сужается — на 1536 с band 1.0 меш рвётся на куски; на 1536 держать 2.0–3.0 |
| | `sign_mode` | udf | udf / sdf | udf — устойчив к грязной топологии; sdf — чистая поверхность и острые кромки (QEF), нужна согласованная ориентация граней |
| | `project_back` | 0.0 | 0–1 | Притянуть вершины к исходной поверхности (1 = точно на неё) — возвращает детали, потерянные DC |
| | `smooth_iters` | 20 | 0–20 | Сглаживание Taubin. По подсказке ноды: 2–3 убирают «лесенку», больше — пересглаживает. **20 = максимум, основной источник «гладких» моделей** |
| | `drop_small_components` | 0.01 | 0–0.5 | Выбросить куски меньше доли от самого большого. 0.01 удаляет мелкие отдельные детали; 0 — не удалять |
| | `fix_poles` | false | — | Чинит T-стыки DC (валентность 3) |
| `DecimateMesh#186` | `target_face_count` | 700 000 | 0–50 M (0 = выкл) | Упрощение до N граней — нужно только для UV/запекания; для чистой геометрии — потеря детали |
| | `placement_mode` | midpoint | midpoint / qem | midpoint бережёт тонкие элементы (рекомендован нодой); qem — оптимальное положение вершин |
| `MeshSmoothNormals#238` | `crease_angle` | 180 | 0–180° | Только шейдинг (нормали), геометрию не меняет. 30–60 — для жёстких поверхностей с рёбрами |

## Что делать с чем

| Симптом | Где крутить |
|---|---|
| Нет частей / части не там / «куски» | `KSampler#3 seed` (перебор), `cfg` 5–7.5, `VaeDecodeStructureTrellis2 resolution` 64, маска (`grow_mask`, качество фото) |
| Форма есть, но поверхность не как на фото | `KSampler#18 steps/cfg`, `CFGOverride#279 start_percent` позже, `MoGe fov_x` вручную |
| Гладко, нет мелкого рельефа | `RemeshMesh smooth_iters` 0–2, `resolution` ≥ формы, `project_back` 1.0, `DecimateMesh` выкл, `target_resolution#94` (осторожно) |
| Меш рваный после remesh | `RemeshMesh band` 2.0–3.0 при высоком `resolution`; `drop_small_components` 0 |
| Долго | `resolution` структуры 32 вместо 64 (−10 мин), текстурная цепочка выкл (−4 мин) |
