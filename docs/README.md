# ComfyUI_ROCM — документация

Собственная сборка ComfyUI и паки нод (модпаки) под GMKtec EVO-X3
(AMD Ryzen AI MAX+ 395, Radeon 8060S / gfx1151, общая память 128 ГБ).

## Цели

1. **Воспроизводимость.** Любое окружение собирается из файлов этого репозитория.
   Никаких правок руками внутри контейнера, которые пропадут при его пересоздании.
2. **Быстрый переход на свежий ComfyUI.** Новая версия ComfyUI должна подниматься
   рядом с рабочей за минуты, проверяться автоматически и так же быстро откатываться.
3. **Свои модпаки.** Набор нод под конкретные воркфлоу, с форками, которые можно
   менять как нужно, без конфликтов между паками.
4. **Выжать железо.** Настройки ROCm, памяти и ключей запуска подобраны под Strix Halo,
   а не под универсальную машину с 32 ГБ.

## Правила ведения

- Решение, которое меняет устройство сборки, — отдельный ADR в `decisions/`.
- Любая правка чужого кода (ComfyUI, ноды) — строка в `patches-registry.md`.
- Исторический журнал ручных правок до начала проекта:
  `/home/ai/comfy/bin/patches/CHANGES.md` (не редактируется, только как источник).
